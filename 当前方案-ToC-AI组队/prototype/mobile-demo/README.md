# 手机端交互 Demo（Prototype）

> PROTOTYPE — 这是用于确认产品流程和视觉方向的抛弃式原型，不是生产代码。

## 需要回答的问题

手机端如何承接“组装协作护照 → 附近发现 → 表达想认识／线下碰卡直连 → 加入项目 → AI 启动任务”，并与未来墨水屏 AI Passport 保持同一套视觉身份？

## 运行

```bash
./run.sh
```

只依赖本机 Python 3，不需要安装前端依赖。建议使用 Chrome、Safari 或手机浏览器打开。

浏览器打开：

- [A — 协作护照](http://localhost:4173/?variant=A)
- [B — 邻近雷达](http://localhost:4173/?variant=B)
- [C — 墨水名册](http://localhost:4173/?variant=C)
- [新用户引导 — 协作护照组装](http://localhost:4173/?variant=C&onboarding=1)

页面底部的原型切换器，或键盘 `←`／`→`，可以切换方向。

## 演示路径

1. 从协作状态与已有项目证据组装协作护照；
2. 在“发现”中选择林澈，查看推荐理由并表达“想认识”；
3. 独立点击“模拟碰卡直连”，模拟双方主动碰卡授权；
4. 邀请对方加入项目；
5. 接受 AI 建议的第一个启动任务；
6. 在“连接”和“项目”中查看结果；
7. 在“我的”中切换活动内可见状态，预览未来墨水屏内容。

所有状态只保存在内存中，刷新页面后重置。

## Demo 边界

- 附近人员和信号强度为预置数据；
- 卡对卡碰触由按钮模拟；
- AI 推荐理由、风险和任务为预置输出，不向用户显示综合匹配分数；
- 没有后端、账户、定位、BLE、NFC P2P 或持久化。

## 验收

```bash
python3 smoke_test.py
```
