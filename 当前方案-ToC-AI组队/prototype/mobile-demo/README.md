# RALLY｜集结 手机端交互 Demo（Prototype）

> PROTOTYPE — 这是用于确认产品流程和视觉方向的抛弃式原型，不是生产代码。

视觉实现遵循 [10-移动端视觉与字体规范](../../10-移动端视觉与字体规范.md)。

## 需要回答的问题

手机端如何作为现场主入口与伴随端，承接“组装协作护照 → 发现 → 表达想认识／线下碰卡 → 连接 → 人类意图澄清 → 双方确认方向 → 入队 → RALLY Room 分工确认”，并在宽屏呈现项目启动舱主工作台？

## 运行

```bash
./run.sh
```

静态原型只依赖本机 Python 3，不需要安装前端依赖。建议使用 Chrome、Safari 或手机浏览器打开。

浏览器打开：

- [发现 · 推荐](http://localhost:4173/?variant=A)
- [发现 · 附近](http://localhost:4173/?variant=B)
- [发现 · 展会名册](http://localhost:4173/?variant=C)
- [新用户引导 — 协作护照组装](http://localhost:4173/?variant=C&onboarding=1)
- [预置 RALLY Room](http://localhost:4173/?variant=A&workspace=1)

推荐和附近是“发现”页的常驻浏览方式；名册只在当前特殊展会由主办方开启后出现。协作护照完整编辑统一放在“我的”。

## 功能层级

1. **RALLY 常驻层**：协作护照、推荐／附近发现、连接、项目协作和个人设置。
2. **展会空间层**：当前原型进入的是 `AI Hardware Hackathon 2026`；展会内公开、现场发现和 SOS 广播都受这个时间边界约束。
3. **展会限定模块**：主办方可为特殊展会开启“展会名册”，只收录明确授权的参展成员；普通场景不展示名册入口。
4. **长期留存层**：展会结束后，展会名册与临时可见性关闭；用户已确认的连接、项目与协作记录继续保留。

## 演示路径

1. 从协作状态与已有项目证据组装协作护照；
2. 在“发现 · 推荐”中一屏浏览一位候选人，左滑暂不看、右滑想认识、点卡查看完整理由；
3. 表达“想认识”，或独立点击“模拟碰卡直连”；两条路径不互为前置；
4. 邀请对方加入项目；
5. 在 RALLY Room 中查看 Agent 建议，主动认领并由人确认首次分工；
6. 在“连接”和“协作”中分别查看长期关系与具体项目；
7. 确认后查看轻量伴随状态、我的启动任务和项目 SOS；
8. 在“我的”中切换展会内可见状态，预览未来墨水屏内容。

默认静态模式的交互状态只保存在内存中，刷新页面后重置。开启 Live 模式后，推荐、附近、名册、连接请求、项目邀请、确认入队、Room 启动计划和任务状态均读取真实后端；刷新页面或更换设备后可以恢复。方向草案／Pivot、Leader 任期、SOS 手机入口和第三方写入同步仍是流程原型或后端独立能力，不能当成已完成的前端闭环。

## Live 模式

先启动 `../../backend`。受保护的本地现场演示可以配置访问码：

```bash
cd ../../backend
DEMO_ACCESS_KEY='replace-with-a-private-demo-key' npm start
```

再启动手机端并打开：

```text
http://localhost:4173/?variant=B&live=1&apiBase=http://127.0.0.1:8787
```

页面使用 RALLY 账号与现场访问码换取可撤销的 Bearer Session；Token 和到期时间保存在本机，刷新后恢复，会话过期会回到登录页，退出登录同时撤销服务端 Session。`demoUser=user-zhou` 只用于显式开启不安全演示身份的可信本地环境，不能部署到公网。

Live 模式会读取后端 `/api/me` 的授权资料；手机“我的”可编辑角色、状态、能力、兴趣、投入时间、协作偏好、当前需求和能力证据，并逐字段控制推荐、附近、名册与 NFC/QR 页面的公开范围。只有打开“发现 · 附近”且资料可见时才启用浏览器 Geolocation；切换页面、锁屏、暂停公开或离开应用会立即停止监听并撤销位置。平台资料只保存用户主动提交的 HTTPS 链接；GitHub 可同步公开摘要，其他平台不爬取内容。

Live 数据请求具有有限退避重试，401 与网络故障分开处理；同一资源的写操作会合并并禁用重复提交。前台恢复时立即同步，活动请求箱和项目状态每 2.5 秒轮询一次。Live 请求失败不会回退到静态人物数据。

## PWA 与真机安全区

- 提供 Web App Manifest、应用图标、Service Worker 和离线失败页；静态壳可离线打开，但 `/api` 与 `/c` 永不缓存，也不会伪造业务成功；
- 页面不再绘制 `09:41`、灵动岛、`5G` 或状态圆点等模拟系统状态栏；
- 顶部和底部布局使用 `safe-area-inset-top`／`safe-area-inset-bottom`，由真机系统状态栏和手势区占位；
- Geolocation 在手机公网访问时仍要求有效 HTTPS；证书、Nginx 与线上部署由部署任务负责，不属于本目录。

## Demo 边界

- 静态模式的附近人员和信号强度为预置数据；Live 模式使用手机 Geolocation 与后端距离分桶，不向他人返回经纬度；
- 推荐页一次聚焦一人并可连续刷完 11 个预置角色，附近和名册也使用完整候选集；
- 卡对卡碰触、QR 扫描和设备挑战仍由按钮或后端契约模拟；
- AI 推荐理由、风险和任务为预置输出，不向用户显示综合匹配分数；
- 手机端只展示启动进度、分工确认、关键动态和 SOS；宽屏三栏工作台不包含聊天、在线文档或长期项目管理；
- 尚未接入正式 OAuth／短信账户体系、真实模型 Agent、BLE、NFC P2P、飞书／GitHub 写入同步与服务器部署；Live 模式使用受保护现场访问码或已有 Bearer Token 接入当前后端；
- Intent Alignment／Direction Version／Pivot-Fork、Leader 任期与交接、数据库版本化迁移和前后端大文件拆分仍待后续实现。

## 验收

```bash
python3 smoke_test.py
python3 live_e2e_test.py

cd ../../backend
npm test
```

`smoke_test.py` 会检查三种发现浏览方式、完整协作闭环、浏览器历史、PWA 壳、真机安全区、横向溢出、浏览器错误，以及手机普通 UI 的最小字号与触控目标，并把截图输出到 `artifacts/`。`live_e2e_test.py` 会启动真实本地 API 与两个独立浏览器上下文，验证登录恢复、资料授权、真实发现、连接、邀请、入队、Room 任务、离页撤销位置和刷新恢复。
