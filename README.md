# AI Collaboration Passport

面向黑客松和高密度共创现场的 To C 实时组队与协作启动产品。

用户通过可授权的 AI 协作护照表达当前状态、能力证据和团队需求；系统解释谁值得认识。主动卡对卡碰触可以建立真实相遇连接，被动 NFC／二维码作为跨手机生态的兼容入口。关系建立后可以继续进入组队、角色建议、首批任务和项目 SOS。

## 手机端 Demo

```bash
cd 当前方案-ToC-AI组队/prototype/mobile-demo
./run.sh
```

打开：

- `http://localhost:4173/?variant=A`
- `http://localhost:4173/?variant=B`
- `http://localhost:4173/?variant=C`

当前稳定展示入口为 C 版。Bonjour 风格的协作护照引导仍在迭代中，未完成部分默认不会进入主演示流程。
